# كريم السوري

موقع طلبات ثابت باللغة العربية، يعمل دون خادم خلفي أو دفع إلكتروني. يختار العميل الأصناف والإضافات، يراجع السلة، ثم يرسل الطلب بنفسه عبر واتساب.

## تشغيل وبناء الموقع

```sh
npm install
npm run build
```

بعد البناء، تُقدَّم ملفات المشروع الثابتة من جذر المستودع، بما فيها `index.html` و`cart.html` و`menu.html` ومجلدا `assets/` و`images/`. يمكن استضافة الموقع على GitHub Pages أو أي استضافة ملفات ثابتة.

## النشر على Vercel

إعداد `vercel.json` يحدد أمر البناء ومجلد النشر `dist/`. عند ربط المشروع، اضبط **Root Directory** على جذر المستودع و**Production Branch** على `main`، واترك Vercel يستخدم إعدادات المستودع. بعد تعديل الإعدادات، أنشئ نشرًا جديدًا لآخر commit على `main`؛ خيار **Redeploy** على نشر قديم قد يعيد نشر commit قديمًا.

## تدفق الطلب

- المنيو والأسعار والإضافات موجودة في `script.js`.
- تُحفظ السلة على جهاز العميل في `localStorage` تحت المفتاح `kareem-cart`.
- يراجع العميل بياناته وإجمالي الأصناف قبل فتح رسالة واتساب الجاهزة؛ لا يُعد الطلب مرسلًا حتى يضغط العميل إرسالًا داخل واتساب.
- إجمالي الصفحة لا يتضمن رسوم التوصيل؛ تُذكر الرسوم بوضوح في ملخص الطلب.
- `menu.html` يحافظ على الروابط القديمة ويوجهها إلى المنيو الجديد.

لتغيير رقم واتساب، حدّث `WHATSAPP_NUMBER` في `script.js` وروابط التواصل المباشر في صفحات HTML.
